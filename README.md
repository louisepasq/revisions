# Nos révisions

Les petites apps de révision d'Henri (CM1) et de Clara (CM2) sur iPad : les tables de multiplication avec une voix qui lit et encourage, et le planisphère. Une app par enfant sur l'écran d'accueil ; la progression est sauvegardée en ligne.

- **Adresse** : `https://nos-revisions.vercel.app`, protégée par un code parent et un code par enfant.
- **Pour les parents** : la page `/parents/`, où l'on choisit le code de chaque enfant et où l'on installe les apps.
- **Pour contribuer** : commencer par [`CLAUDE.md`](CLAUDE.md), qui renvoie aux décisions, à l'architecture et au mode d'emploi.
